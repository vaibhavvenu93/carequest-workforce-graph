# CareQuest Workforce Graph

Workforce intelligence layer for neurodivergence care professionals.

## Purpose

This repo explores how learner progress, simulation performance, certifications, and competency signals can become a verified workforce graph.

## Core Thesis

The care workforce should not be evaluated only by certificates.

It should be evaluated by demonstrated competency, simulation performance, supervision history, and readiness signals.

## What The Graph Tracks

- learner identity
- certification pathway
- completed missions
- simulation scores
- competency strengths
- weak areas
- badges
- readiness score
- placement status

## Long-Term Use Cases

- verified care talent profiles
- employer matching
- certification readiness
- workforce analytics
- training provider dashboards
- global care talent infrastructure
